1. Какие файловые системы вы знаете?
```
NTFS
Основная файловая система Windows. Масштабируемая, безопасная и журналируемая.
FAT32
Не обладает масштабируемостью, безопасностью и журналируемостью. Однако она совместима со многими операционными системами, что делает её популярной для переносных накопителей.
```
2. Как можно классифиировать файловые системы? в чём отличия??
```
По предназначению файловые системы можно классифицировать на нижеследующие категории.

Для носителей с последовательным доступом (например, магнитные ленты): QIC и др.
Оптимизированы для последовательной записи/чтения больших потоков данных. Используются для создания бекапов или архивов.

Для оптических носителей (CD и DVD): ISO 9660, HFS, UDF и др.
Стандарты для чтения/записи оптических дисков, обеспечивают совместимость между приводами и устройствами. Часто ориентированы на распределение данных для чтения.

Виртуальные файловые системы: AEFS и др.
Предоставляет единый интерфейс к разным физическим файловым системам или реализует файловую систему внутри приложения.

Сетевые файловые системы: NFS, CIFS, SSHFS, GmailFS и др.
Позволяют работать с удалёнными файлами как с локальными. Учитывают сетевые задержки, права доступа и особенности транспортировки данных.

Для флэш-памяти: YAFFS, ExtremeFFS, exFAT, F2FS.
Оптимизируют схемы записи для долговечности и скорости.

Отдельно выделяются специализированные файловые системы: ZFS, VMware VMFS и др.
Решают специфические задачи.
```
3. Какие файловые системы используются в linux?
```
ext4 - файловая система по умолчанию для многих дистрибутивов Linux, включая Debian и Ubuntu. Cтабильная, журналируемая, хорошо масштабируется.
XFS - файловая система, которая обеспечивает чрезвычайную масштабируемость числа потоков ввода-вывода, пропускной способности файловой системы, а также размеров файлов и самой файловой системы при использовании нескольких физических устройств хранения.
Btrfs - файловая система, которая предназначена для устранения отсутствия в файловых системах Linux таких возможностей, как объединение носителей в пул, снапшоты, проверка целостности, очистка данных и встроенная поддержка работы с несколькими устройствами хранения.
```
4. Как можно создать файловую систему на диске?
```bash
mkfs [опции] [устройство]

Основные опции
-t [тип] | Указать тип файловой системы.
-c       | Проверить диск на повреждённые блоки перед форматированием.
-f       | Принудительно создать файловую систему, даже если раздел содержит данные.
```
5. Как можно подключить диск в систему, что такое монтирование?
```bash
mount [устройство] [точка_монтирования]

Монтирование - это процесс подключения файловой системы устройства или раздела к дереву каталогов операционной системы, чтобы с ним можно было работать как с обычными файлами.
```
6. файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них? Вывести каталоги к которым примонтированы эти файловые системыю
```
procfs - виртуальная файловая система, представляющая информацию о запущенных процессах и параметрах ядра.
cifs - сетевая файловая система, реализующая монтирование и доступа к файлам на Windows/SMB-серверах.
tpmfs - временная файловая система, предоставляющая интерфейс к устройству TPM для работы с ключами и сессиями.
sysfs - виртуальная файловая система, экспортирующая иерархию устройств, драйверов и их атрибутов ядра в виде файлов и каталогов.
```
```bash
[lnx@lnx ~]$ findmnt -t proc   -o TARGET
TARGET
/proc
[lnx@lnx ~]$ findmnt -t sysfs  -o TARGET
TARGET
/sys
```
```

/sys/kernel/security/tpm для tpmfs

```
