1. Что такое шебанг?
```
Шебанг — в программировании последовательность из символов решётки и восклицательного знака ("#!") в начале файла скрипта. Когда скрипт с шебангом выполняется как программа в Unix-подобных операционных системах, загрузчик программ рассматривает остаток строки после шебанга как имя файла программы-интерпретатора.
```
2. Обязательно ли исполняемый файл дожен иметь соотвествующее расширение?
```
Расширение файла не имеет значения, главное правильно указать интерпритатор в шабанге.
```
3. Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)
```bash
#!/bin/bash
set -euo pipefail

cd /home/lnx/Изображения

ls

ls -a

mkdir -p one/two/three

cd one
echo "test" > test.txt

mv test.txt two

cd two
cp test.txt ..

mv test.txt file.txt

echo -e "один\nдва\nтри" > file1.txt
diff file.txt file1.txt || true

sort file1.txt
sort -r file1.txt

cd ..
cd ..
rm -rf one
```
set -euo pipefail включает
```
-e - скрипт немедленно завершится, если любая команда вернёт ненулевой код возврата.
-г - bash выдаст ошибку, если используется переменная, которая не была объявлена.
-o pipefail - В пайпах возвращается код первой команды, которая завершилась с ошибкой, а не последней.
```
