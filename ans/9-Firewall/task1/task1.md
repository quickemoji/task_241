4. Откройте нужный порт на сервере чтобы восстановить подключение
```bash
[student@S-vm-211 ~]$ sudo iptables -I INPUT 1 -p tcp --dport 211 -j ACCEPT
[student@S-vm-211 ~]$ sudo iptables -I OUTPUT 1 -j ACCEPT
```
5. Это будет udp или tcp прот?
```
Это будет tcp
```

7. Как их сохранить?
```
создать юнит
```
```bash
[student@S-vm-211 ~]$ sudo iptables -I INPUT 1 -p tcp --dport 211 -j ACCEPT
[student@S-vm-211 ~]$ sudo iptables -I OUTPUT 1 -j ACCEPT
[student@S-vm-211 ~]$ sudo iptables-save | sudo tee /etc/iptablestest
# Generated by iptables-save v1.8.10 on Tue Dec 30 14:36:10 2025
*filter
:INPUT ACCEPT [1326:94869]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [310:28345]
-A INPUT -p tcp -m tcp --dport 211 -j ACCEPT
-A OUTPUT -j ACCEPT
COMMIT
# Completed on Tue Dec 30 14:36:10 2025
[student@S-vm-211 ~]$ sudo vi /etc/systemd/system/iptablestest.service
[student@S-vm-211 ~]$ cat /etc/systemd/system/iptablestest.service
Description=Загрузка правил
After=network.target

[Service]
Type=oneshot
ExecStart=/sbin/iptables-restore /etc/iptablestest

[Install]
WantedBy=multi-user.target
[student@S-vm-211 ~]$ sudo systemctl daemon-reload
[student@S-vm-211 ~]$ sudo systemctl enable iptablestest.service
```
